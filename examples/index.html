bem-broom — runnable examples

Each page builds the same app in a different library — and all four share one stylesheet (src/shared/), because bem-broom emits the same class names everywhere. Run with npm run dev.

  • @bem-broom/core — bem() wiring a UI by hand (no framework)
  • @bem-broom/react — useBem / withBem
  • @bem-broom/webcomponents — @bem decorator & BemElement mixin on plain custom elements
  • @bem-broom/lit — the @bem decorator on Lit
